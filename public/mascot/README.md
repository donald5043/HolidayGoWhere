# Q胖 (Q-Pang) 吉祥物素材

把 ChatGPT 產生的 8 張 PNG 放進這個資料夾，**檔名必須完全一致**，網站會自動套用：

| 檔名 | 用途 | 建議尺寸 |
|---|---|---|
| `qpang_full.png` | 完整站立形象 | 1024×1280 |
| `qpang_waving.png` | 揮手（首頁 Hero / 空狀態） | 1024×1280 |
| `qpang_camera.png` | 拿相機（探索相關） | 1024×1280 |
| `qpang_map.png` | 看地圖（地圖／找不到內容） | 1024×1280 |
| `qpang_jumping.png` | 跳躍（收藏空狀態／完成） | 1024×1280 |
| `qpang_logo.png` | 含字 Logo（可選） | 1024×1224 |
| `qpang_icon.png` | 大頭 Icon（Header logo） | 512×512 |
| `favicon.png` | 瀏覽器分頁 Icon | 64×64 或更大 |

## 注意

- 在 PNG 放進來之前，網站會顯示 `placeholder.svg`（一個簡易版 Q胖），不會出現破圖。
- 背景請輸出**透明 PNG**，吉祥物才能漂亮地疊在 Hero 與卡片上。
- 放好檔案後直接重整頁面即可看到效果，無需改任何程式碼。
